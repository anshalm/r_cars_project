# r_cars_project
# R Cars Descriptive Statistics Project

Hi everyone! This project focuses on descriptive statistics 
in R using three self-made car datasets built in Excel and 
loaded into R. It covers the full pipeline from data cleaning 
to statistical analysis to visualization. Please leave 
feedback — it would be much appreciated, thank you!

## What This Project Covers
- dplyr — group_by, summarise, filter, slice_max, slice_min, 
  arrange, left_join, mutate, reframe
- stringi — stri_replace_all_regex for cleaning currency values
- plotly — interactive bar chart of average price per brand
- DescTools — Mode() for statistical mode calculation
- librarian — shelf() for package management
- Descriptive Statistics — sum, mean, mode, median, 
  standard deviation, variance, summary

## Key Findings
- Volvo has the highest average car price at $45,910
- Tesla has the highest median price at $48,475
- Hyundai has the highest price spread — SD of $22,294 — 
  ranging from $17,844 to $62,433, targeting both budget 
  and premium market segments
- Overall price distribution is perfectly symmetric — 
  mean and median both equal $37,930

## Datasets
Three self-made datasets created in Excel:
- car_brands — 99 observations, 8 variables
- customer_data — 99 observations, 3 variables  
- car_company — 12 observations, 4 variables
